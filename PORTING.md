# Porting the engine sounds into PERP

This guide adds only the new engine sounds to PERP. You don't need a tuning menu, handling
changes, stability assist, speed limiter, ignition key or HUD. The cars drive exactly as PERP's
vehicle scripts say. Only what you hear changes.

Paths are relative to this addon unless stated. Background: `CLAUDE.md`.

## How it fits PERP

PERP's cars come from four workshop packs:

| Pack | Holds | Changed by this port? |
|---|---|---|
| 2103606343 | TDM car models (`models/tdmcars/...`) | no |
| 2894498893 | TDM materials and stock engine recordings (`sound/vehicles/tdmcars/...`) | no |
| 2897742669 | PERP's own content (`sound/perp2.5/...`, materials, models) | gets `sound/audio_engine/` |
| 3792392486 | PERP's vehicle scripts (`scripts/vehicles/{tdmcars,jarheads,perp2}/`, plus tier copies in `used/`, `upgrade_1/`, `upgrade_2/`, `spiked/`) | no |

- **Cars are matched by model.** `sh_carlist.lua` maps all 165 PERP cars to their model path and engine.
  Every tier and variant (`used`, `upgrade_1/2`, `spiked`, `_cop`, `_taxi`...) uses the same model,
  so it gets the same engine sound.
- **Top speed comes from the spawned script.** The server reads each car's `MaxSpeed` when it spawns,
  so an `upgrade_2` car gets longer gears in the sound than a `used` one. Nothing is written back to the car.
- **The sounds are pre-rendered.** All 75 distinct engines are WAV files in `sound/audio_engine/`
  (42 folders, ~170 MB). Clients only play files: nothing is generated in game.
- **No vehicle script edits are needed.** The TDM engine recordings are muted at runtime by soundscript name.

## 1. Content

1. Re-bake only if the synth, presets or car list changed since the last bake:
   `cd dev/baker && npm install && node bake.js` (~6 min).
2. Copy `sound/audio_engine/` into PERP's content pack, next to `sound/perp2.5/` in 2897742669,
   and re-upload the pack. A separate pack also works, as long as the server adds it with
   `resource.AddWorkshop("<id>")` like the others.

Clients that don't have the files yet still hear the cars, but each engine is generated in game
instead (~2 s CPU each, limited by `audio_engine_maxsounds`). So it is safe to deploy the Lua before the
content update reaches everyone.

## 2. Lua

The easiest route is a server-side addon, for example `garrysmod/addons/perp_engine_sound/`.
It only needs Lua: the content comes from the workshop pack.

```
lua/autorun/audio_engine_init.lua      (the loader below)
lua/audio_engine/sh_config.lua         copied unchanged
lua/audio_engine/sh_presets.lua        copied unchanged
lua/audio_engine/sh_drivetrain.lua     copied unchanged
lua/audio_engine/sh_carlist.lua        copied unchanged
lua/audio_engine/sh_perp.lua           copied; delete the spawn-menu block at the end (step 4)
lua/audio_engine/cl_baked.lua          copied unchanged (generated by the baker)
lua/audio_engine/cl_synth.lua          copied unchanged (only used as the fallback above)
lua/audio_engine/cl_soundbank.lua      copied unchanged
lua/audio_engine/cl_engine.lua         copied unchanged
lua/audio_engine/sv_engine_sound.lua   new, step 3
```

Don't copy these files. They hold the extras:

| File | What it does |
|---|---|
| `sv_engine.lua` | ignition key that holds the car until start-up ends, tuning net message, `!engine` |
| `sv_handling.lua`, `sv_perp_physics.lua` | anti-spin, traction control, physics changes |
| `sv_stability.lua` | stability assist |
| `sv_cruise.lua` | speed limiter (middle mouse) |
| `cl_menu.lua` | tuning menu |
| `cl_hud.lua` | rpm/speed HUD |
| `lua/autorun/sl65amg_rtu_vehicle.lua`, `models/`, `materials/`, `scripts/` | this addon's test police car |

Loader (`lua/autorun/audio_engine_init.lua`):

```lua
-- Audio Engine: engine sounds for PERP's cars (sound only)
AUDIO_ENGINE = AUDIO_ENGINE or {}

local base = "audio_engine/"
local shared = { "sh_config.lua", "sh_presets.lua", "sh_drivetrain.lua", "sh_carlist.lua", "sh_perp.lua" }
local client = { "cl_baked.lua", "cl_synth.lua", "cl_soundbank.lua", "cl_engine.lua" }

if SERVER then
	for _, f in ipairs(shared) do AddCSLuaFile(base .. f) end
	for _, f in ipairs(client) do AddCSLuaFile(base .. f) end
end

for _, f in ipairs(shared) do include(base .. f) end

if SERVER then
	include(base .. "sv_engine_sound.lua")
else
	for _, f in ipairs(client) do include(base .. f) end
end
```

To put the files inside PERP's gamemode instead, keep the same load order and change `base` to
the folder you put them in.

`sh_config.lua` also registers this addon's SL65 test car (`models/plpd/sl65amg_rtu.mdl`).
Without that model on the server it never matches anything, so it is safe to leave in.

## 3. Server file

Create `lua/audio_engine/sv_engine_sound.lua`. It sends each client the engine on/off state,
the driver's keys and the car's top speed, which is all the sound needs. It never changes how a car drives:

```lua
--[[
	Audio Engine, sound only (server). Networks what every client's engine sound follows:
	engine on/off, the driver's keys and the car's top speed. It never touches how the car
	drives: PERP's vehicle scripts stay in charge.
]]

local E = AUDIO_ENGINE
local tracked = {}

local function track(veh)
	if not IsValid(veh) or not veh:IsVehicle() or not E.GetCarConfig(veh) then return end
	tracked[veh] = true
	-- the top speed of the script it spawned with (base, used, upgrade_1/2, spiked):
	-- the clients space the gears up to it. GetVehicleParams speeds are inches/s
	local ok, p = pcall(veh.GetVehicleParams, veh)
	if ok and istable(p) and istable(p.engine) and (p.engine.maxSpeed or 0) > 0 then
		veh:SetNW2Float("audio_vmax", p.engine.maxSpeed / 17.6 * 1.609344)
	end
end

hook.Add("OnEntityCreated", "audio_engine", function(ent)
	timer.Simple(0, function() track(ent) end)
end)

-- on = start-up sound (or the stop sound when off); instant = straight to idle, no start-up
function E.SetEngine(veh, on, instant)
	veh:SetNW2Bool("audio_on", on)
	if on then
		local car = E.GetCarConfig(veh)
		veh:SetNW2Float("audio_on_t", instant and 0 or CurTime())
		veh:SetNW2Bool("audio_emo", car ~= nil and car.emotionStart == true)
	end
end

-- like TDM's stock sounds: the engine starts as the driver gets in and stops as they get out
hook.Add("PlayerEnteredVehicle", "audio_engine", function(ply, veh)
	if not tracked[veh] then track(veh) end
	if tracked[veh] and not veh:GetNW2Bool("audio_on", false) then E.SetEngine(veh, true) end
end)

hook.Add("PlayerLeaveVehicle", "audio_engine", function(ply, veh)
	if tracked[veh] then E.SetEngine(veh, false) end
end)

-- the driver's W / S / Space / steering, for the rpm model on every client
hook.Add("Think", "audio_engine", function()
	for veh in pairs(tracked) do
		if not IsValid(veh) then
			tracked[veh] = nil
		else
			local drv = veh:GetDriver()
			local bits = 0
			if IsValid(drv) then
				if drv:KeyDown(IN_FORWARD) then bits = bits + 1 end
				if drv:KeyDown(IN_BACK) then bits = bits + 2 end
				if drv:KeyDown(IN_JUMP) then bits = bits + 4 end
				if drv:KeyDown(IN_MOVELEFT) ~= drv:KeyDown(IN_MOVERIGHT) then bits = bits + 8 end
			end
			if bits ~= veh.audioInBits then
				veh.audioInBits = bits
				veh:SetNW2Int("audio_in", bits)
			end
		end
	end
end)

-- lua refresh
for _, ent in ipairs(ents.GetAll()) do track(ent) end
```

The start-up sound takes about a second, as TDM's did. The car can already drive during it, and
the revs pick up once it ends. Each client runs the rpm and gear model from these networked keys,
so the server sends only a few bits per car whenever a key changes.

**If PERP has its own ignition** (keys, fuel, engine toggle), delete the two `PlayerEnteredVehicle` /
`PlayerLeaveVehicle` hooks. Then call `AUDIO_ENGINE.SetEngine(veh, true/false)` wherever PERP turns
an engine on or off. Use `instant = true` for a car that should already be running, with no start-up sound.

## 4. Stock TDM sounds

`sh_perp.lua` mutes the old engine recordings at runtime. It points their soundscripts (`242turbo_idle`,
`370z_firstgear`...) at `common/null.wav` on the server and on every client. Against PERP's current scripts it mutes
904 soundscripts across every tier and variant. It keeps the 32 that other vehicles share
(bus, fire trucks, ambulances, tow trucks), so those vehicles still sound as before. No vehicle script needs editing,
and a newly added car is picked up as soon as it is in `sh_carlist.lua`.

In `sh_perp.lua`, delete everything from `-- spawn menu entries` to the end. It lists the cars in the
sandbox spawn menu, for testing only.

Server convars (replicated):

| Convar | Default | Effect |
|---|---|---|
| `audio_engine_mutestock` | 1 | mute the TDM engine recordings of the 165 cars |
| `audio_engine_muteskid` | 1 | mute the TDM brake screech (`tdmcars_skid`, `_less`; spiked rim scrape kept) |
| `audio_engine_mutetyrescrape` | 1 | mute the glass-bottle/dirt scrape of sliding tyres (global game sounds) |

The last two aren't engine sounds. Set them to 0 to keep PERP's tyre sounds as they are now.
The new tyre roar and wind sound play either way.

## 5. What players can change

Client convars, all optional: `audio_engine_volume` (0-2), `audio_engine_roadnoise`,
`audio_engine_windnoise`, `audio_engine_doppler`, `audio_engine_passby`. `cl_engine.lua` also creates
`audio_engine_startkey`, which does nothing in this port.

## 6. Test

1. Check coverage against PERP's real packs:
   `node dev/baker/test_integration.js <workshop>/3792392486/content <workshop>/2103606343/content`
   It must end with `all checks passed`. It currently reports 165 PERP cars, and 166 baked cars
   (the 165 plus the SL65) sharing 75 engines, all loading from baked files.
2. On the server:
   - Every PERP car starts when you get in, revs and changes gear with its own sound, and stops when you get out.
   - No TDM recording plays underneath.
   - Service vehicles (bus, fire truck, ambulance) still use their old sound.
   - The server console shows `[Audio Engine] muted ... TDM engine sounds`.
   - A client with the content shows no `[Audio Engine] ...: generated N sounds` lines in console:
     everything played from files.

## Optional: no in-game generation at all

To drop the fallback from step 1 (clients without the content stay silent instead of generating),
leave out `cl_synth.lua` and strip `cl_soundbank.lua`:

1. Delete `build`, `buildEnv` and the DSP helpers above them.
2. Delete the `Think` queue hook, `prebuild`, `Bank.RebuildAll`, `audio_engine_rebuild` and both
   `cvars.AddChangeCallback` calls.
3. Delete the convars `samplerate`, `genbudget`, `maxsounds` and `baked`, and the `cvBaked`
   check in `bakedFiles`.
4. Replace `Bank.Build`, `Bank.Get` and `Bank.GetEnv` with:

```lua
local NOBANK = { ready = false }

-- false = no baked files for this engine (checked once, not every frame)
function Bank.Build(cfg)
	local b = bakedBank(cfg) or false
	Bank.list[cfg.id] = b
	return b or nil
end

local function find(cfg)
	local b = Bank.list[cfg.id]
	if b == nil then b = Bank.Build(cfg) end
	return b or nil
end

function Bank.Get(cfg, fallback)
	return find(cfg) or (fallback and find(fallback)) or NOBANK
end

function Bank.GetEnv()
	Bank.env = Bank.env or bakedEnv() or NOBANK
	return Bank.env
end
```
